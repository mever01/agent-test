## 2. Классификация видов проверок

Все проверки в проекте разделены по трём методическим категориям:

1. **`[E2E ручное]`** — Сквозное тестирование пользовательских сценариев через HTTP API (Swagger UI / cURL) на живом стеке сервисов (FastAPI + PostgreSQL + RabbitMQ + Ollama).
2. **`[Авто + мок LLM]`** — Автоматизированное тестирование сценариев оркестратора LangGraph и внешних контрактов с изоляцией недетерминированного вывода LLM через предсказуемые фикстуры и транспортные моки.
3. **`[Unit / Integration]`** — Изолированная валидация компонентов ядра: математика чанкинга, строгие Pydantic-схемы, транзакционность DAO, безопасность хэширования паролей, механизмы брокера AMQP.
